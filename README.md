# 📊 IT Support Ticket Analysis

## 📌 Project Overview

**IT Support Ticket Analysis** is an end-to-end data analytics project developed using **Microsoft Excel and Google Sheets** to analyze IT support operations and derive actionable business insights.

The project focuses on identifying operational bottlenecks, evaluating agent performance, measuring customer satisfaction, and providing strategic recommendations for improving IT support efficiency through interactive dashboards and data-driven analysis.

---

## 🎯 Objectives

* Analyze IT support ticket trends over time.
* Evaluate ticket resolution performance across different request categories.
* Measure customer satisfaction and agent efficiency.
* Identify high-performing and underperforming agents.
* Assess the impact of ticket severity on resolution time.
* Provide management recommendations for improving IT support operations.
* Build an interactive executive dashboard for decision-making.

---

## 📂 Dataset Information

The dataset contains approximately **97,000+ IT support tickets** with information such as:

* Ticket ID
* Date
* Employee ID
* Agent ID
* Agent Name
* Request Category
* Issue Type
* Severity
* Priority
* Resolution Time (Days)
* Satisfaction Rate
* Age
* Age Group

## 🔍 Key Insights

* Ticket volume shows a steady increasing trend over time.
* Hardware and System requests require the longest resolution times.
* Urgent tickets are prioritized and resolved faster than normal tickets.
* Performance varies across agents, highlighting opportunities for targeted training.
* Customer satisfaction remains generally high despite increasing workload.
* Operational bottlenecks are process-related rather than purely staffing-related.

---

## 💡 Management Recommendations

* Upgrade the ticket management software with automation and smart routing.
* Create specialized teams for Hardware and System issue handling.
* Implement targeted technical and customer-service training programs.
* Automate repetitive requests such as Login Access tickets.
